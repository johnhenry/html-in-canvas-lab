Findings

Works

Effects survive nesting

Pixelation, localized distortion, and animated color processing compose across three nested Canvas 2D boundaries. Each parent captures the processed bitmap produced by its child.

Likely bug

DOM clicks stop working

Once HTML-in-Canvas is active, the deepest real DOM button renders but does not receive pointer clicks through the ancestor canvases. The ordinary-DOM fallback remains interactive.

Interpretation

Painting and hit-testing diverge

Recursive bitmap composition appears functional, while hit-test geometry is not propagated through the same nested canvas chain. This looks like an implementation bug or an unimplemented edge of the experimental API.

Tested with the experimental HTML-in-Canvas implementation enabled in Chromium. The API is under active development; behavior may change.
